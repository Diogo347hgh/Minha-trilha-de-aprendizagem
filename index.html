O que aprendi

Versionamento

Aprendi que o versionamento permite registrar e acompanhar as alterações feitas em um projeto.

Git e GitHub

Git é um sistema de controle de versão. GitHub é uma plataforma usada para armazenar e compartilhar repositórios.

Repositórios e commits

Aprendi a criar um repositório com git init, adicionar arquivos e registrar alterações através de commits.

Branches e Merge

Aprendi a criar branches para desenvolver funcionalidades e usar git merge para integrar as alterações.

GitHub remoto

Aprendi a usar git push para enviar alterações e git pull para receber alterações do GitHub.

Clonar e colaborar

Aprendi a usar git clone e que um fluxo simples de colaboração é: pull, editar, commit e push.

.gitignore

Aprendi que o .gitignore indica arquivos e pastas que não devem ser versionados.

README.md

Aprendi que o README.md é utilizado para explicar e documentar o projeto.

Comandos Git

  • git init - inicia um repositório
  • git status - verifica os arquivos
  • git add . - prepara os arquivos
  • git commit -m "mensagem" - cria um commit
  • git log --oneline - mostra o histórico
  • git branch - mostra as branches
  • git merge - integra uma branch
  • git clone - clona um repositório
  • git pull - recebe alterações
  • git push - envia alterações
