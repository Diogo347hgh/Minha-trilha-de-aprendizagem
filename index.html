O que aprendi

Aprendi a criar repositórios, registrar alterações com commits, trabalhar com branches, realizar merges e publicar projetos no GitHub.

Comandos Git

  • git init — inicia um repositório Git.
  • git status — mostra o estado dos arquivos.
  • git add . — prepara as alterações para o commit.
  • git commit -m "mensagem" — registra uma alteração.
  • git branch — lista ou gerencia branches.
  • git merge — integra alterações de uma branch.
  • git pull — baixa atualizações do repositório remoto.
  • git push — envia commits para o GitHub.
